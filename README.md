# ARHEO · Vinča

[Igraj u pregledaču](https://dusanvukic.github.io/arheo-play/)

Probna web verzija arheološke match-3 igre. Na telefonu koristiti uspravan ekran.

Napredak se čuva u ovom pregledaču na ovom uređaju; brisanje podataka sajta može obrisati napredak. Za prvo pokretanje potreban je internet.

Ovaj repozitorijum sadrži samo izvezenu igru. Ažuriranja se pripremaju iz aktivnog Godot projekta, uz proveru spiska dozvoljenih resursa.
